# SkillFactory: Проект «Игра Угадай число»

Этот репозиторий создан в рамках обучения на курсе SkillFactory (направление Data Science).  
Здесь собраны учебные материалы и проекты, выполненные в процессе прохождения модуля.

## 📁 Структура репозитория

- **game_project/** — папка с проектом «Угадай число»
- **lesson3.py** — учебные задания
- **main.py**, **test.py** — вспомогательные файлы
- **game.ipynb** — ноутбук с оформленным проектом
- **game.py**, **game_v2.py** — версии игры

## 🎮 Описание проекта «Угадай число»

Проект посвящён созданию программы, которая угадывает загаданное число за минимальное количество попыток.
