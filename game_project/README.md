# Проект: Игра «Угадай число»

## 🎯 Какой кейс решаем

Необходимо написать программу, которая угадывает загаданное число за минимальное количество попыток.  
Компьютер должен угадывать число эффективно, используя оптимальную стратегию.

## 📊 Какие данные используем

- Загаданное число от 1 до 100.
- Количество попыток, которое потребовалось алгоритму для угадывания.

## 🛠 Этапы работы над проектом

1. Создание простой версии игры, где компьютер угадывает число случайным образом.
2. Улучшение алгоритма — переход к стратегии бинарного поиска.
3. Оформление проекта в Jupyter Notebook.
4. Подготовка финальной версии игры в виде Python‑скрипта.
5. Создание структуры проекта и документации.

## 📈 Результаты

- Реализована функция, угадывающая число в среднем менее чем за 7 попыток.
- Создана улучшенная версия игры (`game_v2.py`).
- Проект оформлен в соответствии с требованиями SkillFactory.
